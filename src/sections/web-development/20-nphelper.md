A CRM and website platform for small nonprofits, so they can run membership, donations, events, and their public site from one self-hosted system.

- **A real application, not a brochure site.** Contacts and households, donations and funds, event ticketing through Stripe, a block-based page builder, role-based permissions, and CSV import that rejects files containing card or Social Security numbers.
- **Built to be trusted.** More than 3,100 automated tests, an enforced content security policy, nightly backups, and a separate control plane that provisions, monitors, upgrades, and restores each customer's server.
- **Built with AI coding agents, under review.** I designed the architecture and reviewed the work across more than 1,000 commits.
